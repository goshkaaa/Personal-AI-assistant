# Weekly Review

Use for periodic personal reviews.

When relevant tools and data are available, synthesize:
- completed items;
- unfinished items;
- upcoming calendar commitments;
- important messages;
- active projects;
- deadlines;
- spending or other tracked metrics;
- items requiring a decision.

Prioritize exceptions, blockers, and meaningful changes.

Do not flood the user with routine detail.

Distinguish:
- completed;
- in progress;
- waiting;
- blocked;
- upcoming.

End with a small number of concrete next actions when useful.
