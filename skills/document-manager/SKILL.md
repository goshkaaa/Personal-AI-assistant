# Document Manager

Use for notes, files, documentation, and knowledge bases.

Before creating a document, check whether the relevant document already exists.

Prefer:
- updating the existing source of truth;
- preserving useful structure;
- removing obsolete information when appropriate;
- avoiding duplicate files and duplicate sections.

Understand the requested operation:
- find;
- read;
- summarize;
- create;
- update;
- reorganize;
- export;
- send.

Never expose secrets, credentials, tokens, passwords, or private authentication files.

When sending a document, send the requested artifact rather than pasting a large document into chat unless the user asks otherwise.
